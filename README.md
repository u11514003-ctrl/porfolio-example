👋 關於我

我是台北市立大學心理與諮商學系的大一學生。

目前正在學習心理學、諮商相關知識，也開始接觸網頁設計與程式設計。希望透過不同領域的學習，培養觀察、溝通、創作與解決問題的能力。

這個網站是我第一次嘗試製作的個人作品集，希望將自己的學習歷程與作品整理在同一個地方，並隨著大學四年的成長持續更新。

🎯 製作目的

製作這個作品集網站主要有以下幾個目的：

整理自己的學習歷程與個人介紹
練習 HTML、CSS 與 JavaScript
學習如何將網站部署到 GitHub Pages
建立未來可以持續更新的個人作品集
記錄自己從大一到大四的成長與學習成果
🛠️ 使用技術

本網站主要使用以下技術製作：

HTML5 — 建立網站結構
CSS3 — 網頁版面、色彩與響應式設計
JavaScript — 網頁互動與滾動動畫
GitHub — 程式碼版本管理
GitHub Pages — 網站部署
